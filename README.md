# CBL 93 – Tarifs et inscription

Page « Tarifs et inscription » du Club de Lutte de Bagnolet (CBL 93), exportée depuis Claude Design.

- `index.html` : la page (composant Design Component, rendu côté client)
- `support.js` : runtime `dc-runtime` qui rend le composant
- `images/` : logo, QR code du dossier, illustration

Site statique, aucun build : servir le dossier tel quel (GitHub Pages).
